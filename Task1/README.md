# FinUnion + RetailBank — Data Architecture. Задание 1

## Цель

Проанализировать данные двух организаций, выделить ключевые бизнес-сущности, описать связи между ними, классифицировать данные по критичности и предложить типы хранилищ.

## Состав решения
- определены ключевые бизнес-сущности
- описаны их атрибуты, связи, источники и проблемы качества
- построена ER-модель
- выполнена классификация данных по конфиденциальности и критичности
- определено назначение OLTP, MDM, DWH, Data Lakehouse, объектного хранилища, графовой БД и поискового движка
- выполнено предварительное сопоставление ключевых сущностей с BIAN
