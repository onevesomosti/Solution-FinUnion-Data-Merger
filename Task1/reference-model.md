#### Границы владения
BIAN выступает общим словарём между FinUnion и RetailBank. Вместо попытки напрямую сопоставлять таблицы FU Core и RB Core сначала определяется единый бизнес-смысл сущности. Домены формируются вокруг устойчивых бизнес-возможностей, а не вокруг приложений.

#### Поиск пересечений систем
Например:
- FU CRM + RB CRM = Party Data Management
- FU Core + RB Core = Current Account / Customer Agreement
- FU Cards + RB Cards = Card domain
- FU Loans + RB Loans = Loan / Credit domain

Таким образом, видно не только техническое дублирование систем, но и дублирование ответственности за одни бизнес-сущности.

BIAN-области можно использовать как ориентир для целевых доменов, внутри которых в дальнейшем публикуются продукты данных.
