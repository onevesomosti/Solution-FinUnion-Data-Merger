# FinUnion + RetailBank — Data Architecture. Задание 3

## Цель

Спроектировать целевую архитектуру данных объединённого банка (операционные хранилища, аналитическую платформу, пайплайны данных, каталог данных и модель управления данными).

## Состав решения
- Сформулирована целевая архитектура данных
- Выполнено сравнение архитектурных подходов
- Оформлены пайплайны данных
- Выделены сценарии больших данных
- Выбрана аналитическая модель
- Определены доменные датародукты
