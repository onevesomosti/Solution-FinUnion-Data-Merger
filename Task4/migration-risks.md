# Риски миграции

| Риск | Влияние | Вероятность | Митигация |
| --- | --- | --- | --- |
| Ошибки сопоставления клиентов | Дубли или ошибочное объединение профилей | Высокая | Правила сопоставления и кретерии истинности, карантин, ручная проверка спорных записей |
| Пропущенная дельта | Новый контур отстаёт от источника | Средняя | Контроль offset, повторная загрузка диапазона |
| Конфликт двух мастер-систем | Потеря или перезапись корректных изменений | Высокая на переходном этапе | Матрица мастер систем по портфелю/атрибуту, блокировка конфликтующего потока |
| Изменение схемы | Пайплайн падает либо трактует поле неверно | Средняя | Валидация схем, версионирование контрактов |
| Разные бизнес-правила FU/RB | Одинаковые показатели рассчитываются по-разному | Высокая | Зафиксировать единую бизнес-формулу и Data Owner |
| Несопоставленные справочники | Ошибочные продуктовые и отчётные категории | Высокая | MDM Reference Data, mapping table, DQ |
| Повторная загрузка создаёт дубли | Завышение сумм и количества операций | Средняя | Идемпотентность, дедупликация |
| Поздние данные | Закрытый период изменяется после отчёта | Средняя | Окно перерасчёта и правила для данных, которые получены позже установленного временного окна |
| Неучтённый потребитель legacy | Сервис или отчёт перестаёт работать после отключения | Средняя | Мониторинг использования, read-only период, реестр потребителей |
| Потеря lineage | Невозможно подтвердить происхождение отчётного показателя   | Средняя | Обязательная регистрация pipeline и dataset до публикации |
| Нарушение защиты ПДн при миграции | ИБ и регуляторные риски | Средняя | Шифрование, RBAC, маскирование, контроль экспортов |
| Неверная миграция финансовых данных | Финансовые расхождения и некорректная отчётность | Средняя, влияние критичное | Сверка результатов, Go/No-Go, fallback |
| Data Lake превращается в Data Swamp | Исторические данные становятся непригодны для использования | Средняя | Iceberg + DataHub + Data Owner + DQ |
| Слишком ранний вывод из эксплуатации | Невозможность быстрого возврата | Средняя | Read-only период и вывод только после стабилизации |
