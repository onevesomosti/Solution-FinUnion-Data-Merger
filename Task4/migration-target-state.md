# Образ целевого результата через 12 месяцев

| Вопрос | Целевое состояние через 12 месяцев |
| --- | --- |
| Какие системы остаются | FU CRM, FU Core Banking, FU Card Processing, FU Loan System как целевые профильные системы. MDM Customer Hub, Integration Layer, Kafka/CDC, PostgreSQL DWH, Data Lakehouse на S3 + Iceberg + Trino, Airflow, BI, DataHub |
| Какие системы выводятся | RB CRM, RB Core, RB Cards, RB Loans после переноса соответствующих бизнес-срезов. RB DWH и RB BI после переключения отчётности, RB Point-to-point integrations |
| Какие данные мигрируются | Клиенты и идентификаторы, договоры и участие в договорах, счета, карты, кредиты, продукты и справочники, история транзакций и платежей, обращения, исторические и архивные данные RetailBank |
| Что остаётся в MDM| Golden Record клиента, customer_id, продукты и корпоративные справочники |
| Что остаётся в DWH | Согласованные структурированные данные, управленческие и регуляторные витрины |
| Что переносится в Lakehouse | Большая история операций, карточные и клиентские события, архивные данные и исторические выгрузки |
| Какие потоки переключаются | RB point-to-point > Integration Layer, batch из legacy DWH > управляемые Airflow-пайплайны, критичные изменения > CDC/Kafka, BI > единый DWH/Data Products |
| Критерий завершения | Все критичные сущности сопоставлены, целевые потоки работают в SLA, критичные расхождения отсутствуют, потребители реально работают с новым контуром, legacy-потребители выявлены и переключены, RB-системы переведены в read-only и затем выведены |
