# Проблемные зависимости и риски

| Проблема / зависимость | Последствие |
| --- | --- |
| Разные идентификаторы клиентов FU и RB | Невозможно построить единый профиль, возникают дубли |
| Разные модели счетов и договоров | Ошибки при объединении отчётности |
| Разные статусы карт | Один статус может интерпретироваться по-разному |
| Разные правила кредитных продуктов | Невозможно напрямую объединить кредитные показатели |
| Несинхронизированные продукты и тарифы | Ошибки CRM, BI и продуктовой аналитики |
| Два мастера финансовой сущности в переходный период | Риск конфликта и перезаписи данных |
| Point-to-point интеграции RetailBank | Потоки трудно контролировать и трассировать |
| Задержка синхронизации MDM | CRM может использовать устаревший клиентский профиль | 
| Некачественное сопоставление клиентов | Два человека могут быть ошибочно объединены или один клиент останется дублем | 
| Аналитика напрямую обращается к OLTP | Рост нагрузки на банковские системы | 
| Потеря lineage | Невозможно определить происхождение показателя | 
| Несогласованные загрузки FU и RB | Показатели DWH относятся к разным моментам времени |
