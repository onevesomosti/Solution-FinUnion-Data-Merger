# Мастер-системы

При выборе мастер-систем используется принцип Golden Source: мастер — это не система, где находится больше всего данных, а авторитетный источник конкретной сущности или её части. Для разных сущностей могут использоваться разные мастеры.

В промежуточном состоянии системы FinUnion и RetailBank продолжают работать параллельно, поскольку одномоментное отключение систем RetailBank недопустимо. Для клиентских и справочных данных вводится централизованный MDM, а финансовые сущности остаются в профильных банковских системах.

### Промежуточное состояние

Для финансовых данных на этапе трёх месяцев применяется временное распределённое мастерство хранение:
- портфель FinUnion продолжает обслуживаться FU-системами
- портфель RetailBank продолжает обслуживаться RB-системами
- MDM связывает клиентов через единый идентификатор
- Integration Layer доставляет данные между контурами
- DWH получает копии данных, но не становится их мастером

Такой подход позволяет выполнить интеграцию без остановки клиентских сервисов и без преждевременной миграции финансовых данных.
